# fstats-cli — instructions de session / session instructions

## 🇫🇷 Langue / 🇬🇧 Language

- 🇫🇷 **Répondre toujours en français** — pour toutes les réponses, sauf
  demande explicite contraire de l'utilisateur (« réponds en anglais… »).
  Le code, les identifiants, les messages d'erreur et les termes techniques
  canoniques (exit code, SHA-256, stdout…) restent dans leur forme
  d'origine ; seul le texte des réponses est en français.
- 🇬🇧 **Always answer in French** (this project's working language), unless
  the user explicitly asks for another language. Code, identifiers, error
  messages and canonical technical terms keep their original form.

## Dépôt bilingue / Bilingual repository

- La documentation est **française canonique** (`doc/*.md`) avec
  **miroirs anglais** dans `doc/en/` (même nom de fichier), plus
  `README.md` (fr) / `README.en.md` (en) à la racine. RoadmapFULL.md reste
  un document historique français (essentiel résumé dans les
  ROADMAP-CIBLE et dans sa note bilingue en tête).
- Modifiez la source FR en premier, puis miroirez en EN — jamais l'inverse.
- Canonical docs are French; English mirrors live in `doc/en/`. Edit the
  French source first, then mirror to English — never the other way.
