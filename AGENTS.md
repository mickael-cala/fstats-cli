# fstats-cli — instructions de session

## Langue

- **Répondre toujours en français** — pour toutes les réponses, sauf
  demande explicite contraire de l'utilisateur (« réponds en anglais… »).
- Le code, les identifiants, les messages d'erreur et les termes
  techniques canoniques (exit code, SHA-256, stdout…) restent dans leur
  forme d'origine ; seul le texte des réponses est en français.
