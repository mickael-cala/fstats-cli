## Suggested reading order

1. [`README.en.md`](../../README.en.md) (repository root) — tool overview and usage.
2. `GUIDE-PEDAGOGIQUE.md` — step-by-step onboarding.
3. `SEMANTIQUE.md` — the technical reference (frozen semantics, formats).
4. `VERIFICATION.md` — the journal of every verification (actual outputs).
5. `ROADMAP-CIBLE1/2/3.md` — the delivered targets and their acceptance criteria.

> **Examples**: the repository ships a bilingual demonstration corpus in
> [`exemples/`](../../exemples/README.md) — SCADA logs, FR/EN texts, data
> files, edge cases and a baseline gate, with verified commands.
